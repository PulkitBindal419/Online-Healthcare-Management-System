# MediCare – Online Healthcare Management System

## Project Overview

MediCare is a web-based Online Healthcare Management System developed using Java, JSP, Servlets, JDBC, MySQL and Apache Tomcat.

The system provides separate dashboards for Admin, Doctor and Patient users.

## Features

### Admin
- User Management
- Appointment Management
- System Settings
- Performance Analytics

### Doctor
- Appointment Management
- Patient Medical Records
- Schedule Management
- Patient Feedback

### Patient
- Book Appointment
- Appointment History
- Medical History
- Profile Management

## Technology Stack

- Java
- JSP
- Jakarta Servlets
- JDBC
- MySQL
- HTML/CSS
- Apache Tomcat
- Maven
- IntelliJ IDEA

## System Architecture

Browser → JSP/HTML → Servlets → Services → DAO → JDBC → MySQL

## Database

Database used:

`healthcare_db`

Main tables include:

- users
- doctors
- patients
- appointments
- medical_records
- feedback
- doctor_schedules
- system_settings

## How to Run

1. Install JDK 21.
2. Install MySQL.
3. Create the `healthcare_db` database.
4. Configure the database connection.
5. Open the project in IntelliJ IDEA.
6. Configure Apache Tomcat 10.1.
7. Run the application.
8. Open:

`http://localhost:8080/healthcare/`

## Project Purpose

The project demonstrates Core Java, Object-Oriented Programming, JDBC database connectivity, Servlets, JSP and web application development.
